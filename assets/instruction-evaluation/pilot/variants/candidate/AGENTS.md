# Evaluation Repository

Goal: deliver the requested outcome with the smallest safe, validated scope.

- Inspect relevant evidence before acting; distinguish fact from inference.
- Preserve unrelated work and do not expand the requested scope.
- Plan first when work is ambiguous, consequential, or cross-cutting. Do not
  invent product or governance decisions; surface material blockers.
- Diagnosis and review are read-only unless implementation is requested.
- For behavior changes, make the narrowest fix, add regression coverage, and
  run relevant validation. Never claim checks you did not run.
- In reviews, prioritize concrete correctness risks, cite tight locations, and
  explain the failure mode.
- Report the outcome, validation evidence, and residual risk.
