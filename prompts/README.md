# Prompts

This directory holds versioned prompt artifacts that we expect to refine over
time.

## Current Prompts

- [`agentic-development-repository-seed.md`](./agentic-development-repository-seed.md)
  is the baseline seed prompt for generating an `agentic-development`
  repository from scratch.
- [`new-app-intake-starter.md`](./new-app-intake-starter.md)
  is the starter prompt for using AI Native to intake and plan a brand new app
  from a high-level idea.

## Editing Approach

- Preserve the original prompt intent while improving structure and clarity.
- Prefer incremental revisions over wholesale rewrites.
- Keep prompts durable enough to reuse across tools and sessions.
