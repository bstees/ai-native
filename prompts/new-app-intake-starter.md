# New App Intake Starter

Use this prompt in a new session when you want AI Native to plan a brand new
application from a high-level idea.

## Prompt

```text
Use AI Native to intake and plan a brand new app from this high-level idea:

[PASTE APP IDEA HERE]

Follow the outline in `planning/new-app-intake-outline.md`.

Do not start coding yet.

I want the first-step planning package to include:
- project goal
- v1 scope
- out-of-scope
- critical risks and unknowns
- initial NFR profile
- initial architecture direction
- recommended repo model
- first execution slice

Optimize for the smallest useful plan that would let us start well, not the most detailed plan possible.
```

## Notes

- Use this in a fresh session so the app intake has a narrow goal.
- Reference the outline file rather than re-explaining the process.
- If the app is large or ambiguous, the response should stay in planning mode.
