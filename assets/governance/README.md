# AI Governance

This directory contains the canonical controls for responsible AI use across
AI Native consumer repositories.

Start with the
[`AI Usage Governance Standard`](./ai-usage-governance-standard.md). Use the
supporting artifacts to assess a use case, respond to an incident, and record a
repository's adoption state:

- [`AI Risk Assessment Template`](./ai-risk-assessment-template.md)
- [`AI Incident And Escalation Playbook`](./ai-incident-and-escalation-playbook.md)
- [`AI Governance Adoption Checklist`](./ai-governance-adoption-checklist.md)

Consumer repositories may strengthen these controls. Exceptions must follow
the standard's documented exception process rather than silently weakening the
baseline.
